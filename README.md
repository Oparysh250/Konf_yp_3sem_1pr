# Эмулятор командной строки (вариант 14)

GUI-эмулятор UNIX-подобной оболочки на Python + Tkinter.

## Возможности
- GUI; заголовок окна содержит имя VFS.
- Парсер с поддержкой кавычек.
- Команды: `ls`, `cd`, `du`, `cal`, `tail`, `chmod`, `conf-dump`, `exit`.
- VFS из ZIP-архива, всё в памяти; base64 для бинарных данных.
- CSV-логирование (дата/время, команда, аргументы, статус).
- Стартовый скрипт с комментариями (`#`).

## Установка и запуск
```bash
python src/main.py --vfs vfs/deep.zip --log shell_log.csv --script scripts/start_script.txt
